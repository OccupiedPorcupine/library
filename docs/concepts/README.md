# Concept art

Early layout concepts for the library. The layout is the reference, especially the shelf arrangement. The final visual design follows the porcelain design system (#19) and is free to differ.

| File | What it shows |
| --- | --- |
| `concept-01.png` to `concept-04.png` | Single featured shelf: a row of spines with the selected book pulled forward, tilted and enlarged to show its cover, a reflection below the shelf, filter chips, shelf/grid toggle and a detail bar with "Open book". |
| `concept-05.png` | Home page with several themed shelves stacked vertically ("01 / Probability & statistics", "02 / Finance & markets"...), each scrolling horizontally with its own featured book. |

Book titles and covers in these images are placeholders.

Related issues: #9 (bookshelf view), #19 (design system), #21 (performance budget).
